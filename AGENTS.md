# Febeboo Project Rules & Workflows

## Autonomous Execution (GSD Mode)
- **Direct Action**: Investigate code, trace issues, run tests, and apply fixes proactively without unnecessary conversational delays.
- **Spec-Driven**: For complex multi-part tasks, break work into clean atomic milestones and track progress.
- **Verification**: Ensure code edits compile and run cleanly without regressions.

## Available Custom Workflows
- **`/code review`**: Run an in-depth code review on recent diffs or specific files.
- **`get-shit-done`**: Trigger autonomous end-to-end task execution.
